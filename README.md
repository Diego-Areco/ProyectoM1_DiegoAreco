# Paletas Interactivas

_Paletas Interactivas_ es una aplicación web estática que genera paletas de colores aleatorias con un solo clic. Permite elegir el tamaño de la paleta (6, 8 o 9 colores) y el formato de los códigos (HSL o RGBA). Cada color se muestra junto a su código, y el texto se adapta automáticamente al fondo para mantener una buena legibilidad. Es útil para inspirarse al diseñar una interfaz o elegir los colores de un proyecto.

**Demo:** https://diego-areco.github.io/ProyectoM1_DiegoAreco/

## Tecnologías usadas

- **HTML5 semántico:** `header`, `main`, `section`, `footer`, `label`, `button` y listas.
- **CSS3:** Flexbox, Grid, media queries y tipografía Montserrat (Google Fonts).
- **JavaScript:** Manipulación del DOM y eventos, sin librerías ni frameworks.
- **Git y GitHub:** Control de versiones con commits convencionales.
- **GitHub Pages:** Publicación del sitio estático.

## Cómo ejecutarlo localmente

El proyecto es estático y no necesita instalar dependencias.

1. Clona el repositorio:

```bash
git clone https://github.com/Diego-Areco/ProyectoM1_DiegoAreco
```

2. Abre `index.html` en tu navegador, o ábrelo con la extensión **Live Server** de VS Code.
